# N16：下载准入与收集文件元数据隔离

## 范围

基线：`c2e8140de331de078ecf976a85f63dd140072f39`，PR #105 合并后的 master。
对应 2026-11-14 CSV 第 17 项 `acf_5237c817c15d146f4610e220349c85bb`
及第 24 项 `acf_d49850333b5a0f8b210a47f8b32e5d83`。
不包含其他 CSV 分组，不改变数据库结构或发布版本。

## 行为

1. 公开下载和 hotlink 在元数据锁内完整重读当前文件，而不只刷新下载次数。
   拒绝已删除、待删除、过期、耗尽、收集类型、所有者/存储定位/加密身份变化；
   普通下载还要求密码哈希与已验证的快照一致。Hotlink 检查请求 ID、当前映射及当前可热链资格。
2. 下载密码校验完成后，签发 cookie 前重新取得元数据锁，核对已验证的密码哈希、身份和生命周期；
   改密撤销完成后，旧密码验证结果不能再创建新 token。legacy 哈希升级后的签发也经过此检查。
3. 锁内登记活动下载保护后再扣次数，使用当前完整记录传输。传输层不再重新收费。
   传输失败、远端重定向等原有保护行为保留，不把响应开始当成下载完成。
4. 普通 presign 单文件和 ZIP、普通直接 API 下载统一接入既有管理下载准入。
   ZIP 在所有成员完成验证后才发送归档头、文件名或内容，防止部分输出后才发现成员失效。
   凭据、发起者和接收者授权在锁内重新读取；回调不获取 API key 锁，避免共享条带死锁。
5. 收集下载继续保留最后一次额度、管理员例外和已收费重试语义，并补当前调用凭据校验。
   普通 presign 不扣数；普通 API 的 `increaseCounter` 独立保留。
   收集重试沿用独立两分钟租约，不被已消费的 30 秒 presign 期限误拒；锁内重查真实租约期限及凭据权限，等待不会延长租约。
6. 普通未加密旧文件的 `SizeBytes=0` 仍表示未知大小，可以下载；收集与加密文件不放宽长度验证。
7. `/d/{id}/{filename}` 对收集文件和不存在的 ID 采用相同限流后重定向，渲染前拒绝，
   不泄露名称、大小或密码要求。正常公开文件不变。

## 保证与限制

准入锁为同进程元数据锁，不是跨实例分布式事务。授权用户/凭据与文件记录的跨实体变化
不具备全局线性化保证。保护的是准入前已发生的撤销和状态变化；不承诺中途撤销能收回已发送字节
或终止已准入的流，也不撤销已交给 S3 的外部下载能力。
普通管理下载仍不要求公开分享密码，管理权限与公开密码是两条不同授权路径。
`ServeFile` 保留内部兼容入口；真实公开路由使用 `ServePublicFile`，管理路由使用管理准入。

通过：

```sh
go generate ./...
go test -tags test,noaws ./internal/storage ./internal/webserver/api -count=1
go test -race -tags test,noaws ./internal/storage ./internal/webserver/api ./internal/webserver \
  -run 'TestN16|TestSEC021Presign|TestCollectionDownloadPolicy' -count=1
```

- N16 覆盖过时密码、删除/待删除、期限和次数、所有者、locator、加密、热链映射与资格、取消、
  最后一次额度、当前名称、拒绝不收费/不登记；presign 双主体/凭据撤销、ZIP成员失败；
  旧零大小 raw 文件、直接 API 收集/普通凭据撤销；收集重试独立期限；文件名路由元数据隔离。
- 密码 token 专项确定性时序：持有元数据锁，启动基于旧验证结果的签发，完成改密/删除等及token撤销，
  然后释放锁，断言不生成cookie；另覆盖当前验证成功和签发后再次改密撤销。
- 最后增补后，webserver N16/presign/collection race及既有公开下载/密码/cookie专项重新通过。
- 原有完整 storage/API 测试通过。SEC052 加密失败测试补保存修改后的合成元数据，
  让其继续检验传输失败而非被新的快照身份校验提前拒绝；原失败断言未放宽。
- 原有 presign SQLite/Redis（miniredis）和收集下载测试在 race 下通过。
- 独立代码复审及 N16 定向复跑无阻断。复审发现并修正旧 raw 零大小兼容问题。
